# 🎬 IMDB Market Trend Analysis Dashboard

**Author:** Sunanda Guha

## 📌 Project Overview

This project analyzes movie industry trends using IMDB data to identify audience preferences, genre performance, and engagement patterns.

The goal is to transform raw movie data into actionable insights through data cleaning, exploratory analysis, visualization, and dashboard development.

This project demonstrates skills in:

- Python
- Pandas
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insights Generation
- Tableau Dashboard Development

---

## 🎯 Business Objectives

The analysis answers the following questions:

- Which genres have the highest average ratings?
- Which genres receive the most audience engagement?
- How have movie ratings changed over time?
- What relationship exists between ratings and audience votes?
- Which genres appear most attractive from a content strategy perspective?
