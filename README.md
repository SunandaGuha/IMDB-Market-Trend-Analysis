# Colab-Ready Resume Projects

This folder contains two Google Colab-ready notebooks:

1. IMDB_Market_Trend_Analysis_Colab.ipynb
2. Retail_Sales_Customer_Behavior_Analysis_Colab.ipynb

## How to use in Google Colab
1. Go to https://colab.research.google.com
2. Click File > Upload notebook
3. Upload one `.ipynb` file
4. Run each cell from top to bottom
5. When prompted, upload the real dataset CSV/XLSX
6. Download the generated cleaned CSV files
7. Use those CSV files in Tableau or Power BI

## Suggested real datasets
- IMDB: Kaggle IMDB Movie Dataset
- Retail: UCI Online Retail Dataset or Kaggle Online Retail Dataset

## GitHub upload
Create one GitHub repository for each project and upload:
- the notebook file
- generated cleaned CSV files
- exported summary CSV files
- dashboard image, if available
